Flow

A decision process that shows support and resistance.

Set the question

Name the decision, describe the context, and choose how the group will collect options.

Timebox the process

Keep proposal and voting windows explicit, so every participant knows when the result becomes final.

Score every option

Participants score from -3 to +3. Negative scores are weighted so resistance is visible, not averaged away.

Review before launch

Status quo and Repeat process stay explicit choices instead of hidden defaults.

Features

Built for groups that need a usable answer.

No accounts to vote

Participants can join with a name and focus on the decision instead of account setup.

Resistance is first-class

Negative scores make opposition visible, helping the group avoid brittle decisions.

Proposal collection

Groups can collect options before voting, including template choices for common outcomes.

QR sharing

Decision links can be shared quickly for in-room or remote participation.

Local-first app shape

The native client keeps its own process history and can export results.

Open source

Ukuvota is built in C and Kryon, with the full app source available publicly.
