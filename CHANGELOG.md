# Changelog

## [0.2.0] - 2026-10-07

- Use the same Ukuvota interface on Linux, Android and the web.
- Save browser decisions between visits and download a local backup.
- Collect separate ballots from people sharing a device and return to edit a saved ballot.
- Show ties clearly, ignore abstentions and reject empty ballots or duplicate voter names.
- Include Status quo and Repeat process in every new decision.
- Improve narrow-screen voting and translate the updated manual into all supported languages.
- Preserve existing decisions when an unsupported database cannot be opened.
- Make local storage explicit; online sharing is not connected in this version.

## [0.1.0] - 2026-08-31

- Release Ukuvota for Linux, Android, and the web.
- Support collective decisions with -3 to +3 scoring, visible resistance,
  Status quo, and Repeat process choices.
- Let participants vote without accounts by choosing a display name.
